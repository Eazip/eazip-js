# Security Policy

## Supported Versions

Security fixes are shipped on the latest stable `@eazip/core` and
`@eazip/react` versions. Prerelease versions are supported on a best-effort
basis until their corresponding stable version is published.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to `oss@eazip.io`.

Include the affected package, version, reproduction steps, and the impact you
believe the issue has. We will acknowledge receipt and coordinate a fix before
public disclosure.

Do not open a public GitHub issue for an unpatched vulnerability.
