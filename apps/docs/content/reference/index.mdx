---

Reference is intentionally focused on the APIs most applications should use.
Additional exported types and lower-level helpers remain available through
TypeScript autocomplete, but are not listed here as equal entry points.

| Package | Use it when | Start with |
| --- | --- | --- |
| `@eazip/core` | You use Vanilla JavaScript or want direct control over a ZIP job. | [`createZip()` and `startZip()`](/docs/reference/core) |
| `@eazip/react` | You want a React hook and ready-made progress UI. | [`useEazip()` and `<EazipTray />`](/docs/reference/react) |

## Looking for examples?

Reference pages are for looking up an API while you build. For a guided path,
start with the [Vanilla JavaScript quickstart](/docs/getting-started/javascript)
or [React quickstart](/docs/getting-started/react).

Cloud HTTP endpoints are not part of this SDK Reference. Start with
[When to use Eazip Cloud](/docs/cloud); its HTTP contract belongs to the
separate Cloud documentation area.
