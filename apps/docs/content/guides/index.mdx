Short, copy-pasteable guides for the jobs people reach for Eazip to do most
often — from a plain asset picker to zero-egress cloud exports.

- [Download selected files](/docs/guides/download-selected-files) — turn a
  gallery or asset picker into a single ZIP.
- [Download multiple files as a ZIP from URLs](/docs/guides/create-zip-from-remote-urls) —
  fetch remote files in the browser and start one download.
- [ZIP S3 or R2 objects](/docs/guides/zip-s3-or-r2-objects) — bundle objects from
  signed bucket URLs.
- [Add progress, cancel, and retry](/docs/guides/progress-cancel-retry) — let the
  tray narrate every state for you.
- [Zip GB-scale, 1,000+ URL jobs](/docs/guides/gb-scale-url-jobs) — offload huge,
  many-file archives to the cloud strategy.
- [Zero-egress exports](/docs/guides/zero-egress-exports) — Eazip Cloud ships
  downloads with zero egress fees.
